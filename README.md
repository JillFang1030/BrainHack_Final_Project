# BrainHack Final Project: fNIRS Brain-Behavior Analysis

## Description
This project focuses on the correlation analysis between fNIRS brain activation (Beta values of 3 channels) and behavioral performance scores in typically developed (TD) and dyslexia (DD) groups.

## Repository Structure
- `BrainHack_Final_Project.ipynb`: The main analysis script.
- `.gitignore`: Configured to exclude all raw data files (.xlsx, .csv) to ensure data privacy.

## How to Run Locally
1. Clone this repository.
2. Place the required data files (`DD_for_project.xlsx`, `TD_for_project.xlsx`, etc.) into the same directory.
3. Run the notebook using Jupyter or VS Code.
